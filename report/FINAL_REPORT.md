# Samsung Electronics Equity Research

기준일: 2026-10-10 · KRW bn, 원/주

## 결론

기준 SOTP는 **361,786원**입니다. DS 메모리 이익을 제품군별로 나누고 DX·SDC·Harman의 정상화 이익 및 파운드리 시나리오를 합산했습니다. 3Q26 자료는 기존 저장소에서 잠정치로 표시된 수치이며, 확정 세부 실적이 반영되기 전까지 잠정·미공개 항목을 확정값처럼 사용하지 않습니다.

| 모델 | 주당 결과 | 역할·핵심 읽기 |
|---|---:|---|
| SOTP | 361,786원 | 중심값. 사업별 이익과 자본집약도를 분리 |
| DCF | 423,485원 | 교차검증. 연결 현금전환 및 CAPEX 부담 |
| Segment PER | 326,000원 | 교차검증. 정상화 EPS 50,000원, Foundry/S.LSI 적자 EPS는 N/M |
| RIM | 173,444원 | 하방 점검. ROE가 자본비용으로 하락하는 경우 |

기준 주가는 2026-10-09 종가 262,000원입니다. 네 결과는 역할이 달라 평균하지 않습니다. SOTP와 DCF의 차이는 특히 2027E 순현금 350조원 시나리오와 terminal value 민감성을 검증해야 한다는 신호로 해석합니다.

## valuation 원칙

- DS 메모리: HBM 26%·9.0x, Server DRAM 34%·7.0x, Client/mobile DRAM 22%·4.5x, NAND 14%·3.0x, 기타 4%·2.5x. 유효 EV/EBIT는 6.2x
- 파운드리·S.LSI: TSMC를 기술·CAPEX 비교 기준점으로 두되 보수적으로 반영
- DX: 스마트폰·TV·가전의 정상화 이익에 낮은 multiple 적용
- SDC·Harman: OLED와 전장 이익의 개별 정상화 multiple 적용
- DCF: 연결 매출·영업이익 기반 FCFF로 CAPEX와 운전자본 후 현금 전환을 점검하며 SOTP를 교차 검증
- 순현금: 2027E 350조원은 보고치가 아니라 시나리오 입력이며 DCF/SOTP에서 동일 입력을 공유한다. 2Q26 실제 순현금에서 출발하는 현금 브리지는 아직 추가 검증이 필요하다
- DCF: WACC 9.0%, 장기성장률 2.5%. 명시기간 FCFF 현재가치는 654,791bn, terminal value 현재가치는 1,522,989bn이며 총 지분가치는 2,527,780bn이다. terminal value가 DCF 지분가치의 약 60%이므로 WACC·장기성장률 민감도를 함께 읽는다.
- RIM: 기초 자기자본 600,000bn, 자기자본비용 10.0%, ROE 30.0%에서 2030년 10.4%로 하락, terminal ROE 12.0%와 성장률 2.5%를 적용했다. 장기 잔여이익 공식에는 다음 기간 성장 `(1+g)`를 포함한다.
- Segment PER: HBM·서버 DRAM EPS 16,000원 × 8배, 범용 메모리 EPS 16,000원 × 4.5배, DX·SDC·Harman EPS 18,000원 × 7배를 합산했다. 적자 Foundry/S.LSI는 N/M으로 제외한다. 이는 전사 peer 평균이 아니라 정상화 EPS 시나리오의 교차검증이다.

HBM 9.0x와 나머지 memory scenario multiples는 가설적 입력이다. 이를 정당화하려면 고객 인증·수율·출하·현금전환이 함께 확인되어야 한다. AI 수요라는 단어만으로 프리미엄을 주지 않고, 제품 mix 개선이 EBIT 전망에 이미 들어갔다면 multiple에 다시 더하지 않는다.

삼성전자는 하나의 전사 peer median으로 평가하지 않는다. HBM/server DRAM, 범용 DRAM/NAND, foundry, DX, SDC, Harman 각각의 이익풀과 적합한 metric을 구분한다. 적자 Foundry & S.LSI는 PER에서 N/M 처리하며, SOTP의 회복 시나리오가 별도로 경제적 가치를 다룬다. SK hynix·Micron·TSMC·Apple/Xiaomi·LG Display는 모두 서로 다른 비교 역할을 하며, 다수는 segment operating benchmark 또는 demand proxy다. 직접 비교 가능성, 사이클, CAPEX, 이익기간, 기준일을 충족하지 않으면 수치 평균에 포함하지 않는다. 상세 방법론은 `report/METHODOLOGY_APPENDIX.md`와 `research/` 문서 4종에 기록했다.

## Vintage 주의

저장소의 현 valuation snapshot 날짜는 2026-10-10이며, 3Q26는 잠정치로 분리한다. 모든 시장가격과 peer 추정치는 동일 cutoff가 확인되기 전까지 과거 스냅샷이다. 새 확정 실적 이후 actual, segment forecast, peer market data, valuation parameter의 가치 기여도를 각각 분리해 업데이트한다.
