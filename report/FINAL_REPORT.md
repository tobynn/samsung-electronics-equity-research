# Samsung Electronics Equity Research

기준일: 2026-10-10 · KRW bn, 원/주

## 결론

기준 SOTP는 **361,786원**입니다. DS 메모리 이익을 HBM·Server DRAM·Client/mobile DRAM·NAND·기타로 분리하고, DX·SDC·Harman의 정상화 이익과 파운드리 할인 가치를 합산했습니다. 3Q26 잠정치는 메모리 가격과 AI 수요가 강하게 이어지고 있음을 보여줍니다. 세부 사업부 손익은 10월 29일 확정 발표 후 갱신합니다.

2Q26 메모리 사업은 HBM4 판매를 확대했고 HBM4E 샘플을 주요 고객에게 출하했습니다. 회사는 하반기 서버 DRAM·eSSD·HBM 수요가 공급 부족을 이어갈 것으로 봤습니다.

## valuation 원칙

- DS 메모리: HBM 26%·9.0x, Server DRAM 34%·7.0x, Client/mobile DRAM 22%·4.5x, NAND 14%·3.0x, 기타 4%·2.5x. 유효 EV/EBIT는 6.2x
- 파운드리·S.LSI: TSMC를 기술·CAPEX 비교 기준점으로 두되 보수적으로 반영
- DX: 스마트폰·TV·가전의 정상화 이익에 낮은 multiple 적용
- SDC·Harman: OLED와 전장 이익의 개별 정상화 multiple 적용
- DCF: 메모리 호황의 회계이익이 CAPEX와 운전자본을 거친 뒤 FCF로 전환되는지 점검
- RIM: 메모리 초과 ROE가 장기 지속되지 않는 하방 가정

HBM 프리미엄은 고객 인증, 공급 제약, 이익 지속기간, AI 플랫폼 내 비중에 근거합니다. 범용 DRAM·NAND에 같은 프리미엄을 적용하지 않습니다. Segment PER도 HBM·Server DRAM, 범용 메모리, DX·SDC·Harman, Foundry/S.LSI의 정상화 EPS를 따로 계산합니다.
