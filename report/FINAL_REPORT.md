# Samsung Electronics Equity Research

기준일: 2026-10-10 · KRW bn, 원/주

## 결론

기준 SOTP는 **361,786원**입니다. DS 메모리 이익을 제품군별로 나누고 DX·SDC·Harman의 정상화 이익 및 파운드리 시나리오를 합산했습니다. 3Q26 자료는 기존 저장소에서 잠정치로 표시된 수치이며, 확정 세부 실적이 반영되기 전까지 잠정·미공개 항목을 확정값처럼 사용하지 않습니다.

## valuation 원칙

- DS 메모리: HBM 26%·9.0x, Server DRAM 34%·7.0x, Client/mobile DRAM 22%·4.5x, NAND 14%·3.0x, 기타 4%·2.5x. 유효 EV/EBIT는 6.2x
- 파운드리·S.LSI: TSMC를 기술·CAPEX 비교 기준점으로 두되 보수적으로 반영
- DX: 스마트폰·TV·가전의 정상화 이익에 낮은 multiple 적용
- SDC·Harman: OLED와 전장 이익의 개별 정상화 multiple 적용
- DCF: 메모리 호황의 회계이익이 CAPEX와 운전자본을 거친 뒤 FCF로 전환되는지 점검
- RIM: 메모리 초과 ROE가 장기 지속되지 않는 하방 가정

HBM 9.0x와 나머지 memory scenario multiples는 가설적 입력이다. 이를 정당화하려면 고객 인증·수율·출하·현금전환이 함께 확인되어야 한다. AI 수요라는 단어만으로 프리미엄을 주지 않고, 제품 mix 개선이 EBIT 전망에 이미 들어갔다면 multiple에 다시 더하지 않는다.

삼성전자는 하나의 전사 peer median으로 평가하지 않는다. HBM/server DRAM, 범용 DRAM/NAND, foundry, DX, SDC, Harman 각각의 이익풀과 적합한 metric을 구분한다. SK hynix·Micron·TSMC·Apple/Xiaomi·LG Display는 모두 서로 다른 비교 역할을 하며, 다수는 segment operating benchmark 또는 demand proxy다. 직접 비교 가능성, 사이클, CAPEX, 이익기간, 기준일을 충족하지 않으면 수치 평균에 포함하지 않는다. 상세 방법론은 `report/METHODOLOGY_APPENDIX.md`와 `research/` 문서 4종에 기록했다.

## Vintage 주의

저장소의 현 valuation snapshot 날짜는 2026-10-10이며, 3Q26는 잠정치로 분리한다. 모든 시장가격과 peer 추정치는 동일 cutoff가 확인되기 전까지 과거 스냅샷이다. 새 확정 실적 이후 actual, segment forecast, peer market data, valuation parameter의 가치 기여도를 각각 분리해 업데이트한다.
